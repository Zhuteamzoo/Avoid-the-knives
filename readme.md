# Avoid The Knifes
 
## Desciprtion

This is a little **python** game that I coded. This game is made using **pygame**, and it serves the purpose of showing beginners how to make simple games in python. 

## How to play

When you first run the *Avoid the knifes.py* file you will be met with a starting screen. You can either press **Start** to start the game or hit the **BIG RED BUTTON** to exit the game. Once you are in the game you can use *a* to move left or *d* to move right. You will see that there is waves of knifes falling from the sky which you have to avoid. If one of the knifes hit you then it is game over for you. Furthermore, the knife quantity exponentially increases so that it becomes more and more challenging.
